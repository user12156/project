PaperMate Backend
=================

백엔드는 인증, 문서 분석, 프로젝트 저장, 공유 기능을 제공하는 API 서버입니다.

폴더 역할
---------

```text
app/          API 서버 코드
app/core/     설정, 데이터베이스, 보안, 공통 의존성
app/routers/  기능별 API 라우터
app/services/ 문서 분석, AI 호출, 변환 처리
models/       요청/응답 스키마
```

로컬 개발
---------

필요한 패키지는 `requirements.txt`를 기준으로 설치합니다.

환경 변수는 `.env.example`을 복사해 로컬 전용 `.env` 파일에서만 설정합니다. 실제 키, 토큰, 비밀번호, 서버 주소는 README나 커밋 메시지에 적지 않습니다.

보안 주의 사항
--------------

공개 문서와 저장소에 포함하지 않을 항목:

- 실제 API 키
- OAuth 클라이언트 값과 시크릿
- JWT 시크릿
- 데이터베이스 접속 문자열
- 운영 서버 주소와 IP
- 배포 명령, 서버 접속 방식, 접근 권한 정보
- 실제 사용자 데이터 또는 업로드 문서

운영 배포와 인프라 설정은 팀 내부 문서에서만 관리합니다.

Troubleshooting
---------------

환경 변수 누락이 의심되면 `.env.example`의 항목을 기준으로 로컬 `.env`를 다시 확인합니다.

의존성 오류가 발생하면 사용 중인 Python 버전과 패키지 설치 상태를 먼저 확인합니다.
