PaperMate Frontend
==================

프론트엔드는 PaperMate의 사용자 화면을 제공하는 React 애플리케이션입니다.

주요 역할
---------

- 로그인 및 회원가입 화면
- 문서 업로드와 분석 화면
- 프로젝트, 공유, 마이페이지 화면
- 백엔드 API 호출

로컬 개발
---------

필요한 패키지는 `package.json`을 기준으로 설치합니다.

환경 변수는 `.env.example`을 복사해 로컬 전용 `.env` 파일에서만 설정합니다. 실제 API 주소, OAuth 값, 토큰은 README나 커밋 메시지에 적지 않습니다.

빌드 확인
---------

```bash
npm run build
```

보안 주의 사항
--------------

공개 문서와 저장소에 포함하지 않을 항목:

- 실제 API 주소와 운영 도메인
- OAuth 클라이언트 값
- 토큰, 세션 값, 사용자 식별 정보
- 배포 프로젝트 설정값
- 실제 사용자 데이터 또는 업로드 문서

운영 배포와 외부 서비스 설정은 팀 내부 문서에서만 관리합니다.

Troubleshooting
---------------

환경 변수 누락이 의심되면 `.env.example`의 항목을 기준으로 로컬 `.env`를 다시 확인합니다.

빌드 오류가 발생하면 Node.js 버전과 패키지 설치 상태를 먼저 확인합니다.
